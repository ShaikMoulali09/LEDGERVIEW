Abstract

Ledgerview – Smart Dashboard Builder

Small businesses, freelancers and student teams already hold the data they need, but it sits in spreadsheet exports, billing tools and even printed tables. Turning it into something readable usually means a costly analytics platform or hours of manual chart-making, and most tools expect clean, well-structured data to begin with.

Ledgerview is a web-based dashboard builder that closes that gap. A user can drop in a CSV or spreadsheet, a photo or screenshot of a table, or simply describe the data in plain language, and Ledgerview produces a dashboard of bar, line and doughnut charts. Before anything is charted, an organizer module cleans messy input: it removes title lines, dividers and footnotes, detects the delimiter and header row, drops total and average rows so nothing is double-counted, parses currency and shorthand numbers such as ₹, 12k and 1.5 lakh, merges near-duplicate spellings and normalizes dates. Every change is listed for the user to review. Each column is then recognized as a number, a category or a date, so a suitable chart type is chosen automatically and the dashboard comes with key figures and short insights.

The site also offers sign-up and login, a profile page for managing saved dashboards, and remembers a user's last pasted data, prompt and dashboard. It runs entirely in the browser, with an optional Node.js backend for accounts and saved work, and optional AI-assisted reading of images.

Objectives

  • Go from raw or messy data to a dashboard in a few clicks, with no analytics background.
  • Accept three kinds of input: spreadsheet data, an image of a table, or a written prompt.
  • Clean and explain every correction made to the data, so the result can be trusted.
  • Remember a user's work and keep their saved dashboards in one place.

Technologies used

  • HTML5, CSS3 and JavaScript for the website and dashboard builder
  • Chart.js for the bar, line and doughnut charts
  • Tesseract.js for on-device OCR of table images
  • Node.js and Express for the optional backend (hashed passwords, token sessions)
  • localStorage fallback when no backend is available

About LEDGERVIEW

Built for small teams who deserve clear numbers, not a data team.

Scroll

Most small businesses already have the data they need. It's sitting in a CSV export, a billing tool, or a folder of spreadsheets nobody has opened since the quarter it was made. Ledgerview exists to close that one small, expensive gap between having the numbers and actually seeing them.

We built it after watching the same pattern play out with freelancers, small shop owners and student teams alike: real data, no time to learn a full analytics platform, and no budget for one either. So Ledgerview does one job — turn a spreadsheet into a dashboard — and tries to do it without asking anything of you first.
